## 来源
- Color Hunt — Coffee 主题配色集合：https://colorhunt.co/palettes/coffee
- Color Hunt 是一个社区调色板站点，每个 palette 为 4 色（通常 2 个主色 + 2 个辅色/背景色），
  页面会随社区投票滚动更新，同一 URL 下的具体色卡可能随时间变化。

## 用法约定（待定）
- 本项目的**主指针蓝钢**与**温度染色（冷青蓝 → 琥珀 → 橙红）**是设计骨架，不建议替换。
- Color Hunt 的咖啡/暖棕系更适合用于：
  ① 表盘外壳/表圈材质（皮革/铜色/做旧金属）
  ② 底部引擎行（DECODE / PREFILL / TTFT / 端到端）的文字与分隔色
  ③ 未来若做「日/夜」或「暖色主题」的整套换肤
- 若采用，按 PLAN.md §6 的方式落成 `ui.html` 里的常量（如 `SUB_COLOR`），并在本文件记录
  具体取到的色值与出处日期（Color Hunt 的 palette 会变，必须抄下 hex 值存档）。
